U2AF2 knockdown in K562 and HepG2 cells

A results report produced by rnaseq-splice, a Nextflow pipeline that takes bulk RNA-seq from FASTQ files to differential expression, differential splicing, gene set enrichment and an interactive report in one run. The data are public ENCODE knockdowns of the core splicing factor U2AF2, used as a positive control.

Open the report View the pipeline on GitHub

The report is a single 18 MB HTML file that runs in your browser; allow a few seconds for it to load. Its full result tables are in the tables folder.

The experiment

U2AF2 (U2AF65) recognises the polypyrimidine tract at 3' splice sites, so knocking it down should change splicing widely. ENCODE knocked it down with shRNA in two cell lines and sequenced two replicates per condition.

What the report contains

  • QC and sample structure: read and mapping statistics, PCA and sample correlation.
  • Differential expression: volcano and MA plots, searchable tables and heatmaps (limma/voom).
  • Differential splicing: ΔPSI volcano plots, event types and per-sample PSI heatmaps (rMATS).
  • DE × splicing and across contrasts: genes that change in expression, splicing or both, and how the two cell lines compare.
  • Gene sets: preranked GSEA of expression and over-representation among spliced genes, against MSigDB Hallmark, Reactome and KEGG gene sets, with KEGG pathway maps.
  • Gene lookup: any gene's expression and splicing across samples and contrasts.

Validation

The pipeline's results were compared with ENCODE's own processed differential expression and rMATS results for the same experiments. In K562, log2 fold changes agreed with ENCODE's at r = 0.87 and ΔPSI values of matched splicing events at r = 0.96–0.98, with the pipeline detecting more significant genes and events than ENCODE's older tool versions.

How it was made

rnaseq-splice (pre-release, built on nf-core/rnaseq 3.27.0) with STAR and Salmon, rMATS 4.3.0 with the read-coverage filter, limma/voom, and fgsea against MSigDB 2026.2 gene sets, run on a Linux server with Apptainer. See the README for the pipeline and how to run it on your own data.
