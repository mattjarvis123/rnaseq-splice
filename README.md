# rnaseq-splice: GitHub Pages site

This `gh-pages` branch holds the example output published at
<https://mattjarvis123.github.io/rnaseq-splice/>: a landing page (`index.html`) and the results report of the ENCODE
U2AF2 knockdown positive control (`report/`). It is kept separate from the pipeline code on `main` so the report files
never enter the pipeline's history.

To update the report, replace the files in `report/` with a new render, commit and push this branch.
